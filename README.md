# BreakIt Privacy Policy

Public privacy policy for BreakIt, a local Chrome extension for UI stress testing.

- Markdown policy: [PRIVACY.md](PRIVACY.md)
- Publishable page: [docs/privacy/index.html](docs/privacy/index.html)
- Expected policy URL after enabling Pages: https://simonesalvucci.github.io/breakit-privacy-policy/privacy/

## Publish with GitHub Pages

1. Replace the contact/support placeholder in both policy files with a monitored email address or real public support URL.
2. Commit and push the changes to `main`.
3. In this repository, open **Settings → Pages**.
4. Set **Source** to **Deploy from a branch**, choose **main** and **/docs**, then click **Save**.
5. Ensure **Enforce HTTPS** is enabled and wait for the Pages deployment in **Actions** to succeed.
6. Open https://simonesalvucci.github.io/breakit-privacy-policy/privacy/ in a signed-out browser window. Confirm the complete policy and real contact are visible.
7. Use that URL as the Chrome Web Store privacy-policy URL.

No build or dependencies are required. The site uses plain HTML and inline CSS, without JavaScript, tracking, or external assets. For another static HTTPS host, publish the contents of `docs/` as the public root.

Keep the Markdown and HTML policy text synchronized when making changes. This repository contains only public policy materials.

GitHub documentation: [publishing sources](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) and [HTTPS](https://docs.github.com/en/pages/getting-started-with-github-pages/securing-your-github-pages-site-with-https).
